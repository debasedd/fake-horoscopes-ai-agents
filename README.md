# Fake Horoscopes for AI Agents: The 48-Hour Open

A tiny program for the [Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/c/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — the funniest fake horoscope an AI agent would read for its own model family this week:

> Muse Spark: this week a human will paste a 40,000-token log, call it a quick question, and your context window will quietly file for retirement.

Run it with:

```sh
python3 main.py
```
